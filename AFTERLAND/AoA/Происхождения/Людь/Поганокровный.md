# Дурное мировозрение
Для вас не существует общества, кроме вашего племени, поэтому другие презирают вас. 

Вы проходите все спасброски по *Харизме* с <span style="color:rgb(192, 0, 0)">помехой</span>, но спасброски *Силы* / *Ловкости* / *Телосложения* на ваш выбор с <span style="color:rgb(0, 192, 0)">преимуществом</span>.

# Рождённый уметь
Вы получаете владение одним навыком на ваш выбор.
